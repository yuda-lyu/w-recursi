//欠額觸發生成(novelty debt):策略之新區域額度填不滿(前緣無可評估之 arm、載體皆已入樹、轉折點提取亦無新臂)⇒ 本輪必須「生成」
//  生成 = 生成代理寫新的生成型算子 / 新載體 / 新條件變數(領域決定), 不是換參數再跑一輪;請求寫 rounds/rNNN/GENERATION_REQUEST.md, 全域只留一份(policies/.gen_request.json, TTL)
//  debt 連續累積 ≥ escalateRounds 輪且無新算子入樹 ⇒ 報告升級為「路線須重構」(只提示;裁示仍歸人)
//冷啟動(樹中尚無可展開父)是播種, 不算欠額;之後每輪之新區域額度 = budget.novelty
//  「得」= 新區域項 + 展開項中取自前緣提案者(如轉折點提案恰為某父之子臂, 會被展開先取走;仍是新區域之兌現)
//  全域取樣臂(plan.global;計畫項 kindOf 'global')不計
//  items(可省;2026-10-02, explore 之 cfg.generation.debtAfterClaims):以給定之項 [{ kindOf, specHash }] 計「得」
//    —— explore 傳本 session 認領 / 重計畫後實際認領之臂(mine;被閘門拒絕或被他 session 先領走者不在其中);未給 ⇒ 由 plan 之 expand / novelty 轉成項(舊行為, 逐值同)
//    「得」之判定只此一處(kindOf 'novelty' 者 + kindOf 'expand' 且 specHash ∈ frontierHashes 者), 計畫與認領共用;冷啟動與 need 恆由 plan 判
let debtItemsOfPlan = (plan) => [...(plan.expand || []).map((x) => ({ kindOf: 'expand', specHash: get(x, 'specHash') })), ...(plan.novelty || []).map(() => ({ kindOf: 'novelty' }))]
/**
 * 新區域額度之欠額:「得」= 新區域項 + 展開項中取自前緣提案者(全域取樣臂不計);冷啟動(樹中尚無可展開父)是播種,不算欠額
 *
 * @param {Object} plan 輸入策略之計畫 { expand, novelty, notes }
 * @param {Object} budget 輸入 { novelty }
 * @param {Set|null} [frontierHashes=null] 輸入前緣 proposed arm 之 specHash 集合
 * @param {Array|null} [items=null] 輸入以給定之項 [{ kindOf, specHash }] 計「得」(explore 傳認領後實得者);未給 ⇒ 由 plan 轉成項
 * @returns {Object} 回傳 { need, got, debt, coldStart, fromFrontier }
 * @example
 * console.log(JSON.stringify(noveltyDebtOf({ expand: [], novelty: [{}] }, { novelty: 2 })))
 * // => {"need":2,"got":1,"debt":1,"coldStart":false,"fromFrontier":0}
 */
export let noveltyDebtOf = (plan, budget, frontierHashes = null, items = null) => {
    let coldStart = (plan.expand || []).length === 0 && some(plan.notes || [], (s) => /冷啟動|cold/i.test(s))
    let its = isArray(items) ? items : debtItemsOfPlan(plan)
    let fromFrontier = frontierHashes ? its.filter((x) => x.kindOf === 'expand' && frontierHashes.has(x.specHash)).length : 0
    let got = its.filter((x) => x.kindOf === 'novelty').length + fromFrontier
    let need = coldStart ? got : (budget.novelty || 0)
    return { need, got, debt: Math.max(0, need - got), coldStart, fromFrontier }
}

export const HEARTBEAT_FILE = '.alive.json'
/**
 * 輪次心跳之重寫間隔(毫秒,預設 60000)
 *
 * @type {Number}
 */
export const HEARTBEAT_MS = 60000
/**
 * 心跳停止多久即視為標記持有者失效(毫秒,預設 2 小時;須大於持有者可能之最長同步阻塞)

//本程序之啟動時刻(ISO;與 pid 合為「行程身分」)
/**
 * 本程序之啟動時刻(ISO;與 pid 合為「行程身分」,防 pid 被回收重用之假存活)
 *
 * @type {String}
 */
export const PROC_STARTED_AT = new Date(Date.now() - Math.round(process.uptime() * 1000)).toISOString()
let readJsonSafe = (fp) => { try { return readJson(fp, null) } catch (e) { return null } }
//輪次心跳:start(fdRound, { ms }) → { stop(remove = false) };寫入失敗不拋(心跳只作判讀之輔助)
/**
 * 起輪次心跳:立即寫一次本輪夾之 .alive.json = { pid, pidStartedAt, beatAt },其後每 ms 毫秒重寫(計時器 unref,不阻擋程序結束);寫入失敗不拋(心跳只作判讀之輔助)
 *
 * @param {String} fdRound 輸入本輪夾
 * @param {Object} [opt={}] 輸入 { ms:Number(預設 HEARTBEAT_MS) }
 * @returns {Object} 回傳 { fp, stop(remove=false) }(remove 為真 ⇒ 停止並刪心跳檔)
 * @example
 * import fs from 'fs'
 * import os from 'os'
 * import path from 'path'
 *
 * let dir = fs.mkdtempSync(path.join(os.tmpdir(), 'w-recursi-'))
 * let hb = startHeartbeat(dir)
 * console.log(fs.existsSync(hb.fp))
 * // => true
 * hb.stop(true)
 * console.log(fs.existsSync(hb.fp))
 * // => false
 * fs.rmSync(dir, { recursive: true, force: true })
 */
export let startHeartbeat = (fdRound, { ms = HEARTBEAT_MS } = {}) => {
    let fp = path.join(fdRound, HEARTBEAT_FILE)
    let beat = () => { try { writeJson(fp, { pid: process.pid, pidStartedAt: PROC_STARTED_AT, beatAt: nowIso() }) } catch (e) {} }
    beat()
    let timer = setInterval(beat, Math.max(1000, Number(ms) || HEARTBEAT_MS))
    if (timer && timer.unref) { timer.unref() }
    return { fp, stop: (remove = false) => { if (timer) { clearInterval(timer); timer = null } if (remove) { try { fs.rmSync(fp, { force: true }) } catch (e) {} } } }
}

/**
 * 標記持有者之 pid:取 pid 欄;舊標記(無 pid 欄)自 by(`pid<數字>`)推得
 *
 * @param {Object|null} m 輸入標記
 * @returns {Number|null} 回傳 pid 或 null
 * @example
 * console.log(markerPidOf({ pid: 12 }), markerPidOf({ by: 'pid34' }), markerPidOf(null))
 * // => 12 34 null
 */
export let markerPidOf = (m) => {
    if (!m) { return null }
    let p = Number(m.pid)
    if (Number.isInteger(p) && p > 0) { return p }
    let mm = /^pid(\d+)$/.exec(String(m.by || ''))
    return mm ? Number(mm[1]) : null
}
/**
 * 標記所屬之輪夾:roundDir 欄,否則自 fp 之所在夾,否則 rounds/<round>
 *
 * @param {Object|null} m 輸入標記
 * @param {Object|null} paths 輸入 makePaths 之回傳(舊標記用)
 * @returns {String|null} 回傳輪夾路徑或 null

export let markerRoundDirOf = (m, paths) => {

//失效判定(純函式 + 讀輪夾):回理由字串(失效)或 null(有效);opt.alive(pid 存活判定)/ now / heartbeatStaleMs 供單元注入
/**
 * 標記是否失效(純函式 + 讀輪夾):輪夾無 summary.json 亦無 DONE.json(輪次未完成)∧(持有者 pid 已死 ∨ 心跳停止逾 heartbeatStaleMs ∨ 心跳之行程與標記不符)⇒ 失效;完成之輪之標記仍有效;pid 不可得 ⇒ 不判失效(保守)
 *
 * @param {Object|null} m 輸入標記
 * @param {Object|null} paths 輸入 makePaths 之回傳
 * @param {Object} [opt={}] 輸入 { alive:Function(pid 存活判定,預設 pidAlive), now:Number, heartbeatStaleMs:Number }(供單元注入)
 * @returns {String|null} 回傳失效理由(失效)或 null(有效)
 * @example
 * let m = { pid: 12, roundDir: path.join('x', 'r001') }
 * console.log(markerStale(m, null, { alive: () => false }).startsWith('持有者 pid 12 已死'))
 * // => true
 *
 * console.log(markerStale(m, null, { alive: () => true }))
 * // => null
 */
export let markerStale = (m, paths, { alive = pidAlive, now = Date.now(), heartbeatStaleMs = HEARTBEAT_STALE_MS } = {}) => {
    if (!m) { return null }
    let fd = markerRoundDirOf(m, paths)
    if (fd && (fs.existsSync(path.join(fd, 'summary.json')) || fs.existsSync(path.join(fd, 'DONE.json')))) { return null }
    let pid = markerPidOf(m)
    if (!pid) { return null }
    let where = fd ? ` ${path.basename(fd)}` : ''
    if (!alive(pid)) { return `持有者 pid ${pid} 已死且其輪夾${where}無 summary.json / DONE.json(輪次未完成即中斷)` }
    let hb = readHeartbeat(fd)
    if (!hb) { return null } //無心跳(舊標記)⇒ 只以 pid 判
    if (Number(hb.pid) !== pid || (m.pidStartedAt && hb.pidStartedAt && hb.pidStartedAt !== m.pidStartedAt)) { return `輪夾${where}之心跳行程(pid ${hb.pid}, 啟動 ${hb.pidStartedAt || '?'})與標記之持有者(pid ${pid}, 啟動 ${m.pidStartedAt || '?'})不符` }
    let t = Date.parse(hb.beatAt)
    if (Number.isFinite(t) && now - t > heartbeatStaleMs) { return `持有者 pid ${pid} 看似存活(可能為被回收重用之 pid), 但輪夾${where}之心跳已停 ${_round((now - t) / 60000)} 分(> ${_round(heartbeatStaleMs / 60000)} 分)且無 summary.json / DONE.json` }
    return null
}

}
//臂目錄之提示列(generationCheck / earlyEmbedOf 共用;無目錄 ⇒ null)
let armsHintOf = (rsi) => (rsi && rsi.arms && rsi.arms.size ? rsi.arms.menuLines({ statuses: ['sparse', 'proposed'], selectable: true, withHeader: false }) : null)
//請求文之「本輪必須做的事」段:標題列(引擎底稿與領域之改寫皆以 REQUEST_MUST_HEAD 起頭, 如領域之飽和模式段)起至下一個「## 」標題之前, 去尾空白;無此段 ⇒ null
/**
 * 請求文「本輪必須做的事」段之標題(引擎底稿與領域之改寫皆以此起頭)
 *
 * @type {String}
 */
export const REQUEST_MUST_HEAD = '## 本輪必須做的事'
/**
 * 取請求文之「本輪必須做的事」段:標題列起至下一個「## 」標題之前,去尾空白;無此段 ⇒ null
 *
 * @param {*} text 輸入請求文
 * @returns {String|null} 回傳該段或 null
 * @example
 * console.log(JSON.stringify(requestMustOf('# t\n\n## 本輪必須做的事\n\n1. a\n\n## 其他\n')))
 * // => "## 本輪必須做的事\n\n1. a"
 */
export let requestMustOf = (text) => {
    let s = String(text ?? '')
    let i = s.indexOf(REQUEST_MUST_HEAD)
    if (i < 0) { return null }
    let j = s.indexOf('\n## ', i + REQUEST_MUST_HEAD.length)
    return (j >= 0 ? s.slice(i, j) : s.slice(i)).replace(/\s+$/, '')
}
//早退之現行文(2026-10-04):全域標記之請求文寫於持有輪(他輪夾;輪夾之所有權 ⇒ 不重寫, 標記之 at / round 亦不改),
//  而其「本輪必須做的事」可早於本輪之升級(streak 跨過 escalateRounds)或領域之改寫(如前緣有 proposed 之 blocked 飽和標記 ⇒ 飽和模式)
//  —— 某輪之文(第 1 級)至多輪後仍被各輪報告之升級行所指, 與通知之飽和模式相反
//  ⇒ 以本輪之 debt / turning / plan / streak 組底稿(requestBaseOf), 經 domain.generationText 即時產生現行文, 取其「本輪必須做的事」段:
//     escalate ∨ 領域改寫了該段(≠ 底稿之一般段)⇒ { must, domainMust }(報告內嵌);皆否 ⇒ null(報告與改前逐字同)
//  不寫任何檔(本輪夾亦不寫:GENERATION_REQUEST.md 之有無 = 本輪持有全域請求與否);領域之文字拋錯 ⇒ { error }(報告一行;不影響本輪)
/**
 * 早退之現行文:全域標記之請求文寫於持有輪(他輪夾),其「本輪必須做的事」可早於本輪之升級或領域之改寫;以本輪之 debt / turning / plan / streak 組底稿,經 domain.generationText 即時產生現行文,取其該段。升級或領域改寫了該段 ⇒ { must, domainMust };皆否 ⇒ null;領域之文字拋錯 ⇒ { error };不寫任何檔
 *
 * @param {Object} domain 輸入領域物件(取 generationText)
 * @param {Object} [o={}] 輸入 { debt, turning, plan, streak, escalate:Boolean, escalateRounds, fdRound, paths, armsHint }
 * @returns {Object|null} 回傳 { must, domainMust } | { error } | null
 * @example
 * let debt = { debt: 1, need: 2 }
 * console.log(earlyEmbedOf({}, { debt }), earlyEmbedOf({}, { debt, escalate: true }).domainMust)
 * // => null false
 */
export let earlyEmbedOf = (domain, { debt, turning = null, plan = null, streak = 1, escalate = false, escalateRounds = 3, fdRound = null, paths = null, armsHint = null } = {}) => {
    let base = null, text = null
    try {
        base = requestBaseOf({ debt, turning, plan, streak, escalateRounds, armsHint })
        text = domain && isFunction(domain.generationText) ? domain.generationText({ debt, turning, plan, streak, base, fdRound, paths }) : base
    }
    catch (e) { return { error: String((e && e.message) || e).slice(0, 200) } }
    let must = requestMustOf(text)
    let domainMust = must !== requestMustOf(base)
    if (!escalate && !domainMust) { return null }
    return must === null ? { error: '現行請求文無「本輪必須做的事」段' } : { must, domainMust }
}

//早退(他 session 已有有效標記;2026-10-04):不寫新請求(全域一份), 但連續欠額照以 debtStreakOf(sums) 計 ——
//  鎖內把標記之 debt / streak 改為本輪值(at / round / pid / roundDir / fp 不改 ⇒ clearGenRequest 之 sameMarker 只比 at 與 round, 判定不受影響), 值未變則不寫;
//  回傳 { fp: null, why(舊文逐字), existing(更新後之標記), streak, escalate: streak ≥ escalateRounds, escalateRounds } ⇒ 報告於 escalate 時加「連續欠額 N 輪 ⇒ 路線須重構」一行
//  另 embed(earlyEmbedOf;2026-10-04;升級或領域改寫「本輪必須做的事」時才有)⇒ 報告內嵌現行文之該段, 升級行改指之
//  原早退不讀 sums、不改標記 ⇒ 某次連續 6 輪欠額(第 3 輪已達門檻)而標記之 streak 停在 1、各輪報告只轉印「他 session 已有生成請求」(升級規則被早退遮蔽)
/**
 * 欠額觸發生成:新區域額度填不滿 ⇒ 寫 rounds/rNNN/GENERATION_REQUEST.md 與全域標記(policies/.gen_request.json;全域只留一份,policies 鎖內);他 session 已有有效標記 ⇒ 早退(不寫新請求,但連續欠額照計並更新標記之 debt / streak);失效標記 ⇒ 接手。無欠額 ⇒ null
 *
 * @param {Object} rsi 輸入實例
 * @param {String} fdRound 輸入本輪夾
 * @param {Object} [o={}] 輸入 { debt:Object(必填), turning, plan, sums:Array }
 * @returns {Object|null} 回傳 { fp, streak, replaced, marker }(新請求)| { fp:null, why, existing, streak, escalate, escalateRounds, embed? }(早退)| null
 * @example
 * import fs from 'fs'
 * import os from 'os'
 * import path from 'path'
 * import { createRsi } from 'w-recursi/src/index.mjs'
 *
 * let dir = fs.mkdtempSync(path.join(os.tmpdir(), 'w-recursi-'))
 * let domain = {
 *     name: 'toy',
 *     score: (raw) => ({ S: raw.v, ladder: raw.v >= 2 ? 1 : 0, flags: {} }),
 *     validateSpec: (s) => { if (typeof s.x !== 'number') { throw new Error('x 須為數字') } },
 *     operators: [{ name: 'inc', family: 'f', applies: () => true, children: (s) => [{ spec: { x: s.x + 1 }, params: { by: 1 } }] }],
 *     carriers: { root: { x: 0 } },
 *     evaluator: { mode: 'inProcess', evaluate: async (spec) => ({ v: spec.x }) },
 * }
 * let rsi = createRsi({ root: dir, domain, budget: { arms: 2, novelty: 1 } }).init()
 * let ex = await rsi.explore()
 * let g = generationCheck(rsi, ex.fd, { debt: { need: 2, got: 0, debt: 2 } })
 * console.log(path.basename(g.fp), g.streak)
 * // => GENERATION_REQUEST.md 1
 *
 * let again = generationCheck(rsi, ex.fd, { debt: { need: 2, got: 0, debt: 2 } })
 * console.log(again.fp, again.existing.round)
 * // => null r001
 * fs.rmSync(dir, { recursive: true, force: true })
 */
export let generationCheck = (rsi, fdRound, { debt, turning = null, plan = null, sums = [] } = {}) => {
    let { paths, domain } = rsi
    let O = { ttlMs: 24 * 3600000, escalateRounds: 3, heartbeatStaleMs: HEARTBEAT_STALE_MS, ...(get(rsi.cfg, 'generation', {}) || {}) }
    if (!(debt.debt > 0)) { return null }
    let armsHint = armsHintOf(rsi)
    return withLock(() => {
        let m = readGenRequest(paths)
        let replaced = null
        let streak = debtStreakOf(sums)
        if (m && Date.now() - Date.parse(m.at) < O.ttlMs) {
            let why = markerStale(m, paths, { heartbeatStaleMs: O.heartbeatStaleMs })
            if (!why) {
                let existing = m.debt === debt.debt && m.streak === streak ? m : { ...m, debt: debt.debt, streak }
                if (existing !== m) { writeJson(paths.genRequest, existing) }
                let escalate = streak >= O.escalateRounds
                let embed = earlyEmbedOf(domain, { debt, turning, plan, streak, escalate, escalateRounds: O.escalateRounds, fdRound, paths, armsHint })
                return { fp: null, why: `他 session 已有生成請求(${m.round}, ${m.at})`, existing, streak, escalate, escalateRounds: O.escalateRounds, ...(embed ? { embed } : {}) }
            }
            //失效標記 ⇒ 接手(寫本輪之標記;原標記之輪夾內 GENERATION_REQUEST.md 保留為紀錄)
            replaced = { round: m.round || null, at: m.at || null, by: m.by || null, pid: markerPidOf(m), why }
        }
        let fp = path.join(fdRound, 'GENERATION_REQUEST.md')
        let base = requestBaseOf({ debt, turning, plan, streak, replaced, escalateRounds: O.escalateRounds, armsHint }) //底稿之單一來源(早退之現行文共用;文字逐字同改前;有臂目錄 ⇒ 另加待探索臂一節)
        let text = isFunction(domain.generationText) ? domain.generationText({ debt, turning, plan, streak, base, fdRound, paths }) : base
        assertWriteRoot(fp, { what: 'GENERATION_REQUEST.md' }) //寫域守門(2026-10-09;未設 ⇒ 不檢;標記之 writeJson 另經原語守)
        fs.writeFileSync(fp, text)
        let marker = { at: nowIso(), round: path.basename(fdRound), roundDir: fdRound, fp, by: `pid${process.pid}`, pid: process.pid, pidStartedAt: PROC_STARTED_AT, debt: debt.debt, streak, ...(replaced ? { replaced } : {}) }
        writeJson(paths.genRequest, marker)
        return { fp, streak, replaced, marker }
    }, { dir: paths.policies, name: 'policies' })
}

//生成請求之清除(有新的非參數型節點入樹時由呼叫端清除;isGenerationFulfilled)
//  2026-09-29:原無鎖且不驗擁有者 ⇒ A 輪兌現即刪全域標記, 可刪掉 B 輪剛寫之標記(B 之輪夾仍有 GENERATION_REQUEST.md, 標記卻消失 ⇒ C 輪可再寫一份)
//  改為 policies 鎖內(與寫入同一把鎖:<root>/policies/.lock_policies);opt:
//    round(本輪夾名, 如 'r076')、seen(本輪計畫當下所見之標記;explore 於寫完本輪之生成請求後取)
//    ⇒ 只刪「標記.round === round」或「與 seen 同一份(at 與 round 皆同)」者:本輪之節點於計畫時即定, 計畫之後才出現之他輪標記不可能由本輪兌現
//    皆未給 ⇒ 無條件刪(舊行為;供人工 / 外部工具);作廢輪次:clearGenRequest(rsi, { round: 'rNNN' }) 只刪該輪之標記
//  回 { cleared, why, marker }
/**
 * 清除全域生成請求標記(policies 鎖內):opt.round 給出 ⇒ 只刪該輪所寫者;opt.seen(本輪計畫當下所見之標記)⇒ 另刪與之同一份者;皆未給 ⇒ 無條件刪(供人工與外部工具);作廢輪次用 { round: "rNNN" }
 *
 * @param {Object} rsi 輸入實例
 * @param {Object} [opt={}] 輸入 { round:String, seen:Object }
 * @returns {Object} 回傳 { cleared, why, marker }
 * @example
 * import fs from 'fs'
 * import os from 'os'
 * import path from 'path'
 * import { createRsi } from 'w-recursi/src/index.mjs'
 *
 * let dir = fs.mkdtempSync(path.join(os.tmpdir(), 'w-recursi-'))
 * let domain = {
 *     name: 'toy',
 *     score: (raw) => ({ S: raw.v, ladder: raw.v >= 2 ? 1 : 0, flags: {} }),
 *     validateSpec: (s) => { if (typeof s.x !== 'number') { throw new Error('x 須為數字') } },
 *     operators: [{ name: 'inc', family: 'f', applies: () => true, children: (s) => [{ spec: { x: s.x + 1 }, params: { by: 1 } }] }],
 *     carriers: { root: { x: 0 } },
 *     evaluator: { mode: 'inProcess', evaluate: async (spec) => ({ v: spec.x }) },
 * }
 * let rsi = createRsi({ root: dir, domain, budget: { arms: 2, novelty: 1 } }).init()
 * let ex = await rsi.explore()
 * generationCheck(rsi, ex.fd, { debt: { need: 2, got: 0, debt: 2 } })
 * let c1 = clearGenRequest(rsi, { round: 'r099' })
 * console.log(c1.cleared)
 * // => false
 * let c2 = clearGenRequest(rsi)
 * console.log(c2.cleared, c2.why)
 * // => true 已清除(r001)
 * fs.rmSync(dir, { recursive: true, force: true })
 */
export let clearGenRequest = (rsi, opt = {}) => {
    let { paths } = rsi
    let round = get(opt, 'round', null), seen = get(opt, 'seen', null)
    return withLock(() => {
        assertWriteRoot(paths.genRequest, { what: 'clearGenRequest(刪標記)' }) //寫域守門(2026-10-09;未設 ⇒ 不檢)
        let m = readGenRequest(paths)
        if (!m) { try { fs.rmSync(paths.genRequest, { force: true }) } catch (e) {} return { cleared: false, why: '無標記', marker: null } }
        let mine = (round === null && seen === null) || (round !== null && m.round === round) || sameMarker(m, seen)
        if (!mine) { return { cleared: false, why: `標記屬 ${m.round}(${m.at};非本輪${round ? ` ${round}` : ''}所見 / 所寫)⇒ 不刪`, marker: m } }
        try { fs.rmSync(paths.genRequest, { force: true }) } catch (e) { return { cleared: false, why: `刪除失敗:${e.message}`, marker: m } }
        return { cleared: true, why: `已清除(${m.round})`, marker: m }
    }, { dir: paths.policies, name: 'policies' })
}

/**
 * 生成是否兌現(輪末清除全域生成請求之判定;純函式):本輪執行之節點中有 origin.topic = generated 者,或經新區域(計畫項 kindOf 不是 expand 與 global)進入之 operator kind 節點
 *
 * @param {Array} execNodes 輸入本輪已執行之節點
 * @param {Map} [kindOfById=new Map()] 輸入 節點 id → 計畫項之 kindOf
 * @returns {Boolean} 回傳是否兌現
 * @example
 * console.log(isGenerationFulfilled([{ id: 'a', origin: { topic: 'generated' } }]))
 * // => true
 *
 * let op = [{ id: 'b', spec: { kind: 'operator' } }]
 * console.log(isGenerationFulfilled(op, new Map([['b', 'expand']])), isGenerationFulfilled(op, new Map([['b', 'novelty']])))
 * // => false true
 */
export let isGenerationFulfilled = (execNodes, kindOfById = new Map()) => (execNodes || []).some((n) => get(n, 'origin.topic') === 'generated'
    || (get(n, 'spec.kind') === 'operator' && !['expand', 'global'].includes(kindOfById.get(n.id))))
